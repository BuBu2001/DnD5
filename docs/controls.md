# Схема управления (пометка к реализации)

Статус: **реализовано (V0.4.8 + V0.5)** — маппинг действий, камера WASD + зум
колесом, выбор клетки мышью (`game/controls/`, тесты `tests_controls`); боевая
сцена принимает ввод: ЛКМ — выбор/перемещение/атака, ПКМ/Q — отмена, E — конец
хода, Tab и 1…4 — выбор бойца (`CombatPlayScene`, тесты `combat_play_*`).
Панели C/I/L/M и F10 — зарезервированы в схеме, реализация панелей — V1.
Основа: п. 4.1.2.5 и таблица 8.6 ТЗ DOC-04, DOC-01 (действия игрока).
Геймпад (FR-E04) и сенсорный ввод (FR-E05) остаются со статусом V1.

## Принцип

Управление осуществляется **клавиатурой (WASD) и мышью**. Все игровые
действия доступны с клавиатуры; мышь дублирует их для выбора и наведения.
Слой ввода движка остаётся несведущим о правилах (E-D01): игровые действия
(атака, конец хода и т.п.) отображаются на клавиши в слое `game/` через
маппинг действий (FR-E03, FR-E80).

| Клавиши | Действие | Примечание |

| Enter / Space | Подтвердить выбранное действие (атака/перемещение) | |
| E | Конец хода (после подтверждения) | |
| Q | Отмена текущего действия/выбора | |
| C | Панель персонажа | |
| I | Инвентарь | |
| L | Журнал боя | |
| M | Карта/мини-карта | |
| F1 | Панель отладки (уже реализовано) | таблица 8.6 |
| F2 | Музыка вкл/выкл (уже реализовано) | |

## Мышь

| Действие | Назначение |
|----------|-----------|
| ЛКМ по своему бойцу | Выделить бойца |
| ЛКМ по пустой клетке | Переместить выделенного бойца (в пределах оставшегося движения, п. 4.1.8) |
| ЛКМ по противнику | Атаковать выделенным бойцом (если действие доступно) |
| ПКМ | Отменить текущее действие/выбор |
| Колесо | Масштаб камеры (ограничение 0.5×…4×, `Camera2D`) |
| Наведение | Подсветка клетки и всплывающая подсказка (Tooltip) |

## Заметки к реализации

- Координаты курсора → клетка сетки: `Camera2D::screen_to_world` +
  целочисленное деление на размер клетки (32 px), с ограничением по карте.
- Клавиши-цифры 1…9 и Q/E/R/C/I/L/M добавлены в `platform::Key` и маппинг
  `platform/sdl_input.cpp` (V0.4.8).
- Движение бойца тратит футы из `rules::TurnResources::movement_remaining_feet`;
  стоимость клетки — `TacticalGrid::entry_cost_feet` (сложная местность ×2).
- Атака — только через `DiceRoller`/`RulesAdapter` (FR-K102, E-D07),
  результат выводится в журнал боя и панель разбора (E-D12).
- Маппинг рекомендуется оформить таблицей «действие → привязки» в слое `game/`
  с настройкой через конфиг (`assets/config.ini`) — без зашивки в код.
