# CHANGELOG — Двухмерный игровой движок D&D 5e (шифр АБВГ.00004)

Формат версий: V<major>.<minor>[.<patch>] — <описание>. Записи ведутся в обратном хронологическом порядке.

## V0.8 — отдых и восстановление, состязания проверок, напоминание о ресурсах; исправление сборки.

- `rules/rest` — отдых и восстановление (DOC-02, статус M):
  - FR-S60: кубики жизни `HitDicePool` (доступно ровно level штук, минимум один
    на трату); короткий отдых `perform_short_rest` — кость хитов класса
    (assets:/data/classes, поле `hit_die`) + Mod(CON), минимум 0 за кубик,
    восстановление ограничено `hp_max`; слоты заклинаний и ресурсы класса
    восстанавливает игровой слой по флагу `resources_recovered` (E-D01).
  - FR-S61: длинный отдых — `evaluate_long_rest` (≥ 8 часов, из них ≥ 6 сна,
    не чаще одного раза за 24 часа, прерывание ≥ 1 часа напряжённой
    деятельности сбрасывает период) и `apply_long_rest` (полное восстановление
    HP, снятие temp_hp, полное возвращение кубиков жизни по формулировке
    DOC-02; расхождение с RAW зафиксировано в DR-11).
  - AC-K18 (связка): перенастройка предметов `AttunementSet::rest()` применяется
    в момент завершения короткого отдыха (механизм отложенных запросов в rules/items).
- `rules/contest` — состязания проверок (FR-S24, статус M): `resolve_contest`
  — оба броска через единый DiceRoller (FR-K102), преимущество/помеха
  независимо у каждой стороны (FR-S07), при ничьей ни одна сторона не достигает
  цели; строка `description` — для журнала боя без правил в движке.
- UI-S11 (M): `rules::unused_resources_reminder` — в конце хода
  `CombatPlayScene::end_turn` показывает в статусной строке непотраченные
  действие и перемещение; бонусное действие выводится только при наличии
  разрешения (FR-S42), реакции в MVP отключены (FR-K63).
- Тесты: +9 кейсов rules — `rest_hit_dice_pool`, `short_rest_heals_with_hit_dice`,
  `short_rest_rejects_invalid_spend`, `long_rest_gate_rules`,
  `long_rest_full_recovery`, `contest_higher_total_wins`,
  `contest_tie_means_no_one_succeeds`, `contest_advantage_per_side`,
  `unused_resources_reminder`. Итог: 79 кейсов / 1309 проверок, ctest 6/6
  (headless и DND_WITH_SDL2=ON).
- Исправление дефектов сборки V0.7 (headless-конфигурация, NFR-E12):
  `rules/dto.h` — добавлен `#include <cstdint>` (падали game_logic-цели),
  `game/main.cpp` — подавлены unused-but-set переменные параметров окна.
  Обновлены строки версии V0.4 → V0.8 в заголовке окна и журнале запуска.
- Документация: CHANGELOG дополнен записями V0.5…V0.7 (восстановлены по
  истории коммитов), README приведён к состоянию V0.8, `docs/traceability.md`
  — раздел 12, `docs/decisions.md` — DR-11.

## V0.4 — реализация ТЗ игрового движка: ядро, платформа, ресурсы, UI, правила.

- Слой платформы (M1/M2): окно SDL2 + headless-режим (`DND_WITH_SDL2`),
  контекст OpenGL 3.3 Core, собственный загрузчик GL-функций (`gl_loader`),
  ввод (кадровый цикл, маппинг, адаптер ввода→UI, таблица 8.6 DOC-01),
  letterbox-масштабирование, `FrameTimer`, процедурный шрифтовой атлас
  `FontAtlas` (ячейка 16×32, cap height 19.6923 px).
- Отрисовка (M2): `SpriteBatch` (батчинг текстур, ≤8 draw call на кадр,
  E-D05), `Camera2D` с ограничением по карте, примитивы (прямоугольник,
  линия, эллипс), `draw_text` с масштабом и выравниванием, `DebugOverlay`
  (FPS, draw calls, сущности).
- Ресурсы и данные (M3): `VirtualFileSystem` `assets:/`, `JsonLoader`
  (конверт `{$schema, schema_version, id}`, п. 4.5.3), `ResourceCache`
  (FR-E68), `TextureLoader` (TGA + процедурные текстуры), JSON-карты
  со слоями тайлов и объектами; данные: карта 20×15, предметы, бестиарий.
- Сохранения (M6): сериализация состояния партии и RNG, миграция версий.
- UI (M8): виджеты (Label, Button, Panel, ProgressBar, Tooltip, Grid),
  контейнеры (HBox/VBox/Stack), события, масштабирование под 1280×720
  (UI-E02), боевая панель с полным разбором броска (только DTO, E-D12).
- Игра: вертикальный срез боевой сцены (Приложение Д): комната 20×15,
  PlayerFighter + PlayerRogue + 2 Goblins, тактическая сетка, FSM хода;
  `game/adapters/rules_adapter` связывает engine и rules (E-D01).
- Правила: криты/осечки, состояния (conditions), временные хиты,
  сопротивление/уязвимость, сосредоточение (attunement ≤3), экономика
  действий, стек модификаторов по слоям, формулы п. Г.13 (19 шт.).
- Инструменты (M11, этап 1): `json_validator`, `schema_gen`, `map_validator`.
- Тесты: Catch2-совместимый микро-каркас `tests/test_harness.h` (DR-10),
  5 целей (`tests_rules`, `tests_engine`, `tests_platform`,
  `tests_integration`, `tests_golden`), золотой эталон
  `tests/golden/golden_values.txt` (seed 42); 58 кейсов / 957 проверок.
- Качество: `-Wall -Wextra -Werror`, пресеты CMake (MSVC /MTd|/MT, NFR-E14),
  статические проверки `scripts/check_includes.py` (NFR-E10) и
  `scripts/hdrcheck.sh`; проверка сборки MSVC 19.44 и GCC 12.
