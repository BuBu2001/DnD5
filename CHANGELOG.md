# CHANGELOG — Двухмерный игровой движок D&D 5e (шифр АБВГ.00004)

Формат версий: V<major>.<minor>[.<patch>] — <описание>. Записи ведутся в обратном хронологическом порядке.

## V0.4.5 — обновление README и архитектуры под состояние V0.4.

- `README.md`: быстрый старт с `DND_WITH_SDL2`, структура проекта, инструменты,
  бенчмарки, состав тестов — по фактическому состоянию V0.4.
- `docs/architecture.md` переписана: модули по слоям, главный цикл, ECS,
  данные, правила, качество; ссылки на `docs/decisions.md` и матрицу.

  `tests/test_harness.h` исправлена на DR-10.

## V0.4.4 — документация: решения по реализации и полная матрица трассируемости.

- Добавлен `docs/decisions.md` (Приложение Б, п. Б.3): решения DR-01…DR-09 —
  стек SDL2/OpenGL 3.3 с headless-режимом, собственный JSON-парсер, процедурный
  шрифтовой атлас, ECS sparse-set + command buffer, ГСЧ xoshiro256** с инъекцией,

  политика сборки (-Werror, /MT, пресеты), пять уровней тестирования.
- `docs/traceability.md` переписана в полную матрицу (Приложение В): все группы
  FR-E, FR-K и NFR сопоставлены с модулями, символами и проверками; раздел 10 —
  отложённое на V1 (FR-E04/05, E35–E39, E54, E96–E99, подключение стора).

  лог приглушён до Warn, выравнивание таблицы с учётом ширины UTF-8.

## V0.4 — реализация ТЗ игрового движка: ядро, платформа, ресурсы, UI, правила.

- Слой платформы (M1/M2): окно SDL2 + headless-режим (`DND_WITH_SDL2`),
  контекст OpenGL 3.3 Core, собственный загрузчик GL-функций (`gl_loader`),
  ввод (кадровый цикл, маппинг, адаптер ввода→UI, таблица 8.6 DOC-01),
  letterbox-масштабирование, `FrameTimer`, процедурный шрифтовой атлас
  `FontAtlas` (ячейка 16×32, cap height 19.6923 px).
- Отрисовка (M2): `SpriteBatch` (батчинг текстур, ≤8 draw call на кадр,
  E-D05), `Camera2D` с ограничением по карте, примитивы (прямоугольник,
  линия, эллипс), `draw_text` с масштабом и выравниванием, `DebugOverlay`
  (FPS, draw calls, сущности).
- Ресурсы и данные (M3): `VirtualFileSystem` `assets:/`, `JsonLoader`
  (конверт `{$schema, schema_version, id}`, п. 4.5.3), `ResourceCache`
  (FR-E68), `TextureLoader` (TGA + процедурные текстуры), JSON-карты
  со слоями тайлов и объектами; данные: карта 20×15, предметы, бестиарий.
- Сохранения (M6): сериализация состояния партии и RNG, миграция версий.
- UI (M8): виджеты (Label, Button, Panel, ProgressBar, Tooltip, Grid),
  контейнеры (HBox/VBox/Stack), события, масштабирование под 1280×720
  (UI-E02), боевая панель с полным разбором броска (только DTO, E-D12).
- Игра: вертикальный срез боевой сцены (Приложение Д): комната 20×15,
  PlayerFighter + PlayerRogue + 2 Goblins, тактическая сетка, FSM хода;
  `game/adapters/rules_adapter` связывает engine и rules (E-D01).
- Правила: криты/осечки, состояния (conditions), временные хиты,
  сопротивление/уязвимость, сосредоточение (attunement ≤3), экономика
  действий, стек модификаторов по слоям, формулы п. Г.13 (19 шт.).
- Инструменты (M11, этап 1): `json_validator`, `schema_gen`, `map_validator`.
- Тесты: Catch2-совместимый микро-каркас `tests/test_harness.h` (DR-10),
  5 целей (`tests_rules`, `tests_engine`, `tests_platform`,
  `tests_integration`, `tests_golden`), золотой эталон
  `tests/golden/golden_values.txt` (seed 42); 58 кейсов / 957 проверок.
- Качество: `-Wall -Wextra -Werror`, пресеты CMake (MSVC /MTd|/MT, NFR-E14),
  статические проверки `scripts/check_includes.py` (NFR-E10) и
  `scripts/hdrcheck.sh`; проверка сборки MSVC 19.44 и GCC 12.

## V0.2 — добавил Т3 для игрового движка.

- Проанализирован комплект документации проекта (DOC-01…DOC-04, ГОСТ 19.201-78).
- Создан каркас программного кода движка по Приложению Г (п. Г.14) ТЗ DOC-04:
  каталоги `engine/` (core, platform, render, resource, audio, ecs, ui, scene),
  `rules/`, `game/`, `assets/`, `tests/`, `tools/`, `third_party/`, `docs/`.
- Добавлена система сборки CMake (заготовка п. Г.11): цели `engine`, `rules`,
  `game`, `tests`; стандарт C++20.
- Реализованы первые рабочие модули ядра движка (этап M0/M1):
  - `engine/core/log` — логирование с уровнями (FR-E08);
  - `engine/core/result` — тип результата без исключений;
  - `engine/core/event_bus` — событийная шина subscribe/publish/unsubscribe (FR-E10);
  - `engine/core/config` — конфигурация из файла ключ=значение (FR-E09);
  - `engine/core/file_system` — виртуальные пути `assets:/...` (FR-E07, DATA-E05);
  - `engine/platform/timer`, `engine/platform/main_loop` — главный цикл с фиксированным
    шагом логики 60 Гц и ограничением до 5 шагов за кадр (п. 4.1.2.3, формула (2));
  - `engine/ecs` — каркас ECS-lite (entity, registry, component_storage, view, system);
  - `engine/scene` — каркас стека сцен и конечного автомата (state_machine);
  - заглушки интерфейсов слоёв `render`, `resource`, `audio`, `ui`, `platform`
    (реализация — этап M2+).
- Реализованы опорные интерфейсы модуля правил по Приложению Г (п. Г.2–Г.8):
  abilities (modifier = floor((score−10)/2)), dice_roller + random_provider
  (IRandomProvider, E-D07), damage (сопротивления), initiative (tie-breaker п. 4.1.11.3),
  action_economy (TurnResources), turn_state_machine (TurnState, п. 4.1.7.2),
  modifier_stack (слои модификаторов), health (порядок списания урона, п. 4.1.11.4),
  formulas.h (перечень формул п. Г.13).
- Добавлены модульные тесты (п. Г.12, таблица 8.2): таблица модификаторов характеристик,
  DiceRoller (преимущество/помеха/cancelled), инициатива с tie-breaker, списание урона.
- Добавлен исполняемый пример `game/main.cpp` (прогон главного цикла без окна).
- Создана документация каркаса: `README.md`, `docs/architecture.md`,
  `docs/traceability.md` (каркас матрицы трассировки, Приложение В).
- Проверка сборки: `cmake -S . -B build && cmake --build build && ctest` — успешно.
